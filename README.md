# 晚安成电 🌙

晚安成电签到 APP，支持 **自动监听 是否有 签到任务**

此处为 **客户端** 逻辑

最低系统 Android 8.0

> 由于 **晚安成电** 最近更新了利用 **wx.login()** 来实现 签到功能，所以加了 **kotlin 手写 应用宝协议** 和 **YYB-Go-Enhanced 服务器部署** 来解决 这个问题

## 功能 📱

- **我的**
  - **微信登录**，保留 **学校账号登录（CAS）**、**网页登录** 和 **退出登录**
  - 登录 并 刷新 后显示 `学号：`、`姓名：`
  - **关于** 里查看 当前版本，并 **检查更新**
  - **开源** 打开 [UESTC-NightSign-APP](https://github.com/MilLoong/UESTC-NightSign-APP)
- **签到**：读取 当天状态、平台时段、允许地点 及 半径，确认后 提交，再 复查结果
- **设置**
  - **打开地图** 或 **当前位置**，同时填入 GCJ-02 坐标 和 地址
  - 保存后才会用于 签到
  - 本机后台签到 默认关闭
  - **微信授权** 可切换 **手机本地 / 服务端**，分别保留授权配置
  - 本地授权二维码支持 **保存到相册** 或 **保存为图片**
  - 主题可选 天空蓝、清新绿、樱花粉
- **记录**：本机最近 40 条 运行记录

## 使用步骤 ⚙️

1. 打开 **我的 → 微信登录**，进入 设置 选择 **手机本地 / 服务端** 并完成 微信授权，微信 需已在 **成电智慧学工** 绑定 本人学校身份，APP 自动获取 学校会话，无需先登录 CAS
   - **学校账号登录（CAS）**：作为 备用方式，填写 学号 和 统一认证密码，按提示完成 短信验证
   - **网页登录**：点 **我的 → 网页登录**，在 APP 内打开的 学校页面 完成登录，进入 **晚安成电** 页面后，点 右上角 **导入会话**，校验成功后 自动返回 APP 并 刷新状态
2. 打开 **设置**，用 **打开地图** 或 **当前位置** 填入 坐标 和 地址，再点 **保存设置**
3. 在 **设置 → 微信授权** 选择模式
   - **手机本地**：点 **微信登录**，二维码 出现后点 **保存二维码**，将 图片 放到 另一个屏幕 展示，再用 本人微信 扫码 并 确认，返回 APP 等待 登录完成。已登录 可点 **验证授权**
   - **服务端**：点 **连接服务器**，扫描服务器管理页 的 绑定二维码 并 确认地址，在 管理页 完成 微信授权 后，回到 APP 点 **验证授权**
4. 在 **签到** 查看 平台状态 和 允许地点，在 允许时段内 点 **立即签到**，或在 设置 里开启 后台签到

## 运行说明 🔔

- **登录续期**：学校会话 自动恢复，微信授权 失效时 重新扫码。CAS 为 备用方式，仅在勾选 保存账号 后 保存密码，二次认证 需 手动完成
- **退出登录**：关闭 后台签到，清除 本地微信授权 并 重置签到配置
- **后台签到**：约每 15 分钟检查一次，省电限制、断网 或 强行停止 可能导致 漏签，请在截止前 确认结果
- **更新**：启动后 定期检查 新版本，也可在 **我的 → 关于** 手动检查
